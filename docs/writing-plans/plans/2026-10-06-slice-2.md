## Spec readings this plan settles

Where the spec could be read two ways, this plan takes one reading. Implementers follow these and do not reopen them.

1. **A placement that can never fit.** Each placement must fit the host alone (`ConfigError::PlacementNeverFits` names it). `Host::ever_fits` checks each resource on its own, so when every placement fits, the largest of each resource across them fits too: the spec's "a model fits the host when any one of its placements does" adds nothing past the per-placement check, and the model-level `NeverFits` check is not run for a model with placements.
2. **"A sheep no model names"** is not counted at all: there is no footprint to count it at. `measure()` attributes GPU memory only to the sheep serving a model the dog tracks, and to ollama's runners, so an unnamed sheep's GPU processes show up as unaccounted. A sheep serving several configured models is a stand-in, as in slice 1.
3. **The ended line's key.** The spec writes `{"ended": {"reason": ...}}`; slice 1 shipped `{"ended": {"why": ...}}`. Nothing is released yet and the CLI is the only reader, so every ended line moves to `reason` (Task 15), and the CLI reads `reason` in the same commit. An idle end adds `idle_for`, the lease's `release_if_idle` in shep's duration grammar.
4. **A progress note replaces the lease's `note`**, so the status and `state.json` show the latest one. A `PUT` with an empty body is a renewal as in slice 1, and a renewal is never activity.
5. **A request in flight is use.** A lease whose holder has a request in flight for its model has `idle_for` 0 and cannot be released for idleness until the request ends; the request's end is activity.
6. **A reclaimable lease whose model's backend exits ends `reclaimed`**, as an eviction ends it: the model is gone, and the holder takes a new lease if it still wants it. Only held leases load a crashed model again, so a reclaimable lease never claims room ahead of a waiter.
7. **A stray found by an `online` event, or by the survey, is counted at once**, with no ready check: it holds memory now. At start, discovery keeps slice 1's ready check, and a one-model sheep that is not ready counts as a stand-in at the same figures. That diverges from the spec's "laya running when the dog starts is laya" for a laya still starting: a backend that is not ready is not served, and the stand-in counts the same memory until it is evicted or comes back as laya.
8. **Strays never go through the property test.** A stray holds memory the dog did not admit, so it can pass the host by definition. Unit tests cover strays.
9. **Request activity reaches `state.json`** at the next save, and a request from a lease's holder forces a save when the last one is more than a minute old (`ACTIVITY_SAVE`), so a restart restores an idle clock at most a minute stale. A note always saves.
10. **The idle text in a sentence** ("idle for 3h") rounds down to the largest whole unit: hours from one hour, minutes from one minute, seconds below that. The spec's example says "since 08:00"; the plan keeps slice 1's RFC 3339 time for `since`, and Task 15's commit body says so.
11. **A failed first load that the gate now refuses** turns the model Unloaded with its one retry still owed, and the next load (through the gate) is that retry. The retry is owed until a load succeeds or fails again, or until nothing wants the model any more (no waiter, no held lease loading it again), when it is dropped.
12. **`measured` is always an object** in the status, `{"vram_bytes": null, "ram_bytes": null}` for an unloaded or unmeasured model. A figure declared with no VRAM (`vram` unset) drifts on any measured VRAM; a RAM figure left unset counts as 0.
13. **An ollama model's runner is found by its model blob.** `/api/ps`'s `digest` is the manifest's, and the runner's command line names the model layer's blob instead (on the GPU host, ollama 0.35.0: manifest `b94f869e…`, blob `f5f1dd89…`). The dog asks `POST /api/show {"model": <ollama name>}`, takes the blob from the first `FROM <…>/blobs/sha256-<hex>` line of its `modelfile`, and matches it against a command-line argument ending in `/blobs/sha256-<hex>`. The blob is cached per ollama model and asked again only when that model's manifest digest in `/api/ps` changes, which a pull does.
14. **`release_if_idle` must be more than 0.** HTTP refuses 0 with `400 bad_lease_request`, and `run --release-if-idle` refuses it as a usage error.
15. **A model running in a placement the config no longer declares** counts at what it loaded with, as slice 1 counts a model gone from the config. A placement that is still declared counts at the larger of what it loaded with and its new figures.
16. **A version 2 `state.json` names every model holding memory in `models`**, so a sheep record whose model has no `models` entry was stopped by the dog and started by something else: it is a stray. A version 1 file has no `models`, and its sheep records count as the dog's.

## Review Focus

The five failure modes most likely to bite a person running this dog that the spec implies but does not spell out. Each line's test is written in the named task.

1. **A survey read before a model left lists it again.** `/api/ps` or the flock answered while ollama or the sheep was still unloading, or before a stray sheep exited, and the answer is applied after the book marked the model Unloaded. A reasonable person expects the model to stay unloaded, not to come back as a phantom stray holding memory that blocks the next load. Tests `a_survey_from_before_an_unload_does_not_bring_the_model_back` and `a_survey_from_before_a_stray_sheep_exits_does_not_bring_it_back`, Task 14.
2. **A long streamed request from the lease holder outlasts `release_if_idle`.** A benchmark sends one 40-minute generation under a lease with `--release-if-idle 30m`. A reasonable person expects the lease to survive the request, since it is in use the whole time. Test `a_request_in_flight_keeps_its_lease_from_going_idle`, Task 5.
3. **An `online` event races the dog's own restart or stop of that sheep.** The dog's load restarts a sheep, or its eviction stops one and the stop retries, and an `online` for that sheep arrives meanwhile. A reasonable person expects no stray: the dog is the one running it. Tests `an_online_from_the_dogs_own_load_is_not_a_stray` and `an_online_while_the_dog_stops_the_sheep_is_not_a_stray`, Task 11.
4. **A config reload removes the placement a running model loaded in.** A reasonable person expects the model to keep running where it is and to keep counting what it loaded with, so admission neither overcommits the card nor counts VRAM a RAM placement does not hold. Test `a_reload_that_removes_a_loaded_placement_keeps_counting_what_it_loaded_with`, Task 3.
5. **`nvidia-smi` is missing, prints `[N/A]`, or prints something unreadable.** A reasonable person expects the dog to keep serving, with `unaccounted_vram_bytes` absent and VRAM unmeasured, never a crash or a zero that reads as "nothing in use". Tests `without_nvidia_smi_nothing_is_measured_on_the_gpu`, `a_row_whose_memory_is_not_a_mib_figure_is_skipped` and `an_unreadable_line_is_an_error_not_a_zero` in Task 12, and `without_nvidia_smi_the_gpu_figures_are_absent` and `unreadable_nvidia_smi_output_counts_as_absent` in Task 13.

```rust
    pub fn footprint_at(&self, placement: Option<&PlacementName>) -> Footprint {
```

```rust
            .map_or(self.footprint, |p| p.footprint)

    pub fn placed(&self, placement: &PlacementName) -> Model {

/// Reads `raw`, in order, refusing a repeated name, a placement bigger than the host,
/// and placements that set different sheep fields
///
/// # Errors
/// [`ConfigError::Size`], [`ConfigError::DuplicatePlacement`],
/// [`ConfigError::PlacementNeverFits`] and [`ConfigError::PlacementKeysDiffer`].
pub(super) fn build(model: &ModelName, raw: Vec<PlacementSection>, host: &Host) -> Result<Vec<Placement>, ConfigError> {
    let mut placements: Vec<Placement> = Vec::with_capacity(raw.len());
    for section in raw {
        let name = PlacementName::from(section.name);
        if placements.iter().any(|placement| placement.name == name) {
            return Err(ConfigError::DuplicatePlacement { model: model.clone(), placement: name });
        }
        let field = |leaf: &str| format!("models.{model}.placements.{name}.{leaf}");
        let footprint = Footprint {
            vram: parse_vram(section.vram.as_deref(), &field("vram"))?,
            ram: parse_ram(section.ram.as_deref(), &field("ram"))?,
        };
        if !host.ever_fits(&footprint) {
            return Err(ConfigError::PlacementNeverFits { model: model.clone(), placement: name });
        }
        placements.push(Placement { name, footprint, script: section.script, args: section.args, env: section.env });
    }
    check_fields(model, &placements)?;
    Ok(placements)
}

/// Refuses placements that set different sheep fields: a field one sets would outlive it into the next
///
/// # Errors
/// [`ConfigError::PlacementKeysDiffer`] naming the first two placements that differ, and how.
fn check_fields(model: &ModelName, placements: &[Placement]) -> Result<(), ConfigError> {
    let Some((first, rest)) = placements.split_first() else {
        return Ok(());
    };
    let keys = |placement: &Placement| placement.env.keys().cloned().collect::<BTreeSet<_>>();
    for other in rest {
        let what = if first.script.is_some() != other.script.is_some() {
            Some("script".to_owned())
        } else if first.args.is_some() != other.args.is_some() {
            Some("args".to_owned())
        } else {
            keys(first).symmetric_difference(&keys(other)).next().map(|key| format!("env key {key}"))
        };
        if let Some(what) = what {
            return Err(ConfigError::PlacementKeysDiffer {
                model: model.clone(),
                first: first.name.clone(),
                second: other.name.clone(),
                what,
            });
        }
    }
    Ok(())
}
```

```rust
        let options = self.options(&model);
        let fits_now = options.iter().find(|(_, wanted)| self.may_load_as(&model, *wanted)).cloned();
        if let Some((placement, wanted)) = fits_now {
            self.place(&model, placement, wanted);
            self.start_load(now, &model, out);
            return Reason::Loading { model };
        }
        let order = self.in_the_way(now, &model, priority);
        let free: Vec<_> = order
            .iter()
            .filter(|(guard, _)| *guard == Guard::Free)
            .map(|(_, name)| name.clone())
            .collect();

            if let Some(set) = self.eviction_set(&model, *wanted, free.clone()) {
                self.place(&model, placement.clone(), *wanted);
                self.evict(set, &model, out);
                return Reason::Loading { model };

    /// placement that could have room with guards lifted

        now: Moment,

        order: &[(Guard, ModelName)],

            .iter()
            .find_map(|(_, wanted)| self.eviction_set(&model, *wanted, names.clone()))

            return Reason::Behind { model };
        };

                .map(|(_, name)| name.clone())

        if let Some(claimed) = guarded(Guard::Claim).into_iter().next() {
            return Reason::Behind { model: claimed };
        }
        self.grace_reason(now, &guarded(Guard::Grace))
```

Rules, from the spec's "Reclaimable leases":

1. A model only reclaimable leases name is reclaimable, not held: it is a `Guard::Free` or `Guard::Grace` candidate like any unleased model, never named in a `Reason::Held`, never the reason a waiter is refused.
2. While any lease names a model, the model is not unloaded for idleness.
3. When a model is evicted, every reclaimable lease on it ends `Reclaimed` in the same step, with `Persist`.
4. A model named by a held lease and a reclaimable one is held.
5. A reclaimable lease waits like any batch lease (its priority is whatever it asked, batch by default), and its load may evict reclaimable models.
6. A reclaimable lease whose model's backend exits ends `Reclaimed` in that step, with `Persist`, and nothing loads the model again for it (Spec readings 6). Only held leases load a crashed model again, so a reclaimable model never claims room ahead of the queue.
7. The status's `held_by` lists the clients of held leases only.

Rules, from the spec's "Idle leases" and Spec readings 4 and 5:

1. Only two things are activity: a request through the dog for the leased model from the lease holder's own client (at its arrival and at its end), and a progress note. A plain renewal is not.
2. While a request of the holder's for the leased model is in flight, the lease is in use: `idle_since` is `None`, the status's `idle_for` is 0, and it is never released for idleness.
3. A note sets `last_activity`, replaces the lease's `note`, renews a heartbeat lease, and saves (`Persist`).
4. A lease with `release_if_idle` ends `Ended::Idle { after }` once `now >= last_activity + after` and it is not in use. `next_deadline` includes that moment. A lease without it never ends for idleness.
5. When a lease reaches two ends in one step, the earlier one is its reason.
6. A restored lease's `last_activity` is the saved one, or the restart's moment when the save has none.

```rust
use crate::config::{ClientName, ModelName};

impl Book {
    /// Marks the leases `client` holds on `model` as used at `now`
    pub(super) fn touch(&mut self, now: Moment, client: &ClientName, model: &ModelName) {
        for lease in self.leases.values_mut() {
            if lease.ask.client == *client && lease.ask.model == *model {
                lease.last_activity = now;
            }
        }
    }

    /// Counts one more of `client`'s requests for `model` in flight
    pub(super) fn start_use(&mut self, client: &ClientName, model: &ModelName) {
        *self.in_flight_by.entry((client.clone(), model.clone())).or_default() += 1;
    }

    /// Ends one of `client`'s requests for `model`, which is use at `now`
    pub(super) fn end_use(&mut self, now: Moment, client: &ClientName, model: &ModelName) {
        let key = (client.clone(), model.clone());
        if let Some(count) = self.in_flight_by.get_mut(&key) {
            *count = count.saturating_sub(1);
            if *count == 0 {
                self.in_flight_by.remove(&key);
            }
        }
        self.touch(now, client, model);
    }

    /// Whether a request of `lease`'s holder's for its model is in flight
    pub(super) fn in_use(&self, lease: &Lease) -> bool {
        self.in_flight_by
            .keys()
            .any(|(client, model)| *client == lease.ask.client && *model == lease.ask.model)
    }

    /// A progress note: use now, the lease's note from now on, and a renewal of a heartbeat lease
    pub(super) fn note(&mut self, now: Moment, id: LeaseId, note: String, out: &mut Vec<Action>) {
        let Some(lease) = self.leases.get_mut(&id) else {
            return;
        };
        lease.last_activity = now;
        lease.ask.note = Some(note);
        if matches!(lease.ask.hold, Hold::Heartbeat { .. }) {
            lease.renewed = now;
        }
        out.push(Action::Persist);
    }

    /// When `lease` ends for sitting idle, and how: never unless it asked, and not while in use
    pub(super) fn idle_ends(&self, lease: &Lease) -> Option<(Moment, Ended)> {
        let after = lease.ask.release_if_idle?;
        (!self.in_use(lease)).then(|| (lease.last_activity.plus(after), Ended::Idle { after }))
    }
}
```

  - Docs: `Ended::Idle` "Its holder neither used its model through the dog nor sent a note for `after`, and it asked to be released then."; `Event::LeaseNoted` "A lease's holder sent a progress note."; `Reason::Held.idle_since` "When its lease was last used, or `None` while a request of its holder's is in flight."

```rust
async fn serving<'a, S: Shepherd>(
    backends: &Backends<S>,
    saved: &Saved,
    leased: &BTreeSet<&ModelName>,
    sheep: &str,
    models: &[&'a Model],
) -> Option<(&'a Model, bool)> {
```

Rules, from the spec's "Unaccounted GPU memory" and "Drift", and Spec readings 2 and 13:

1. Sizes are `<n> MiB`. Several GPUs sum. A compute-app row whose memory is not a MiB figure is skipped (`nvidia-smi` writes `[N/A]` there when it cannot read a process). Any other line that does not read is an error, never a zero. No GPU line at all is `NoGpu`. The two queries are the ones run on the host for the captures; `memory.total` and `process_name` are read past and unused, so a capture pastes in as a fixture.
2. A sheep model's VRAM is the sum of the compute apps whose pid is its sheep's or one of that sheep's lambs', `None` when none is; its RAM is the flock's `memory_bytes`. An ollama model's VRAM is the sum of the compute apps whose arguments include one ending in `/blobs/sha256-<its blob>`, `None` without a blob or a match; its RAM is never measured. `/api/ps`'s own size is not used: it under-reports by about 3 GB.
3. Unaccounted is `used` less every compute app owned by the tree of a sheep that serves a tracked model, or by an ollama runner (a process whose arguments name any blob in `blobs`). A sheep no tracked model runs on owns nothing, so its GPU memory is unaccounted (Spec readings 2). Unaccounted is `None` without a GPU reading, and while any tracked model declares `vram = "all"`.
4. Drift is a measured figure more than `DRIFT_OVER_PERCENT` (10) percent above the declared one, in VRAM or in RAM, computed in `u128`. `Vram::All` and an unmeasured figure never drift. An undeclared figure counts as 0, so any measured amount of it drifts.
5. `Drifting::update` returns one line when a model starts drifting and one when it stops, and drops a model that is no longer tracked without a line.
6. `blob_of` reads the first line starting `FROM ` whose path's last segment is `sha256-<hex>`, and returns the hex.

```rust
//! What `nvidia-smi` prints, read.

use core::fmt;

const MIB: u64 = 1 << 20;

/// A `<n> MiB` field as bytes
fn mib(field: &str) -> Option<u64> {
    field.trim().strip_suffix(" MiB")?.parse::<u64>().ok()?.checked_mul(MIB)
}

pub(crate) fn reading(totals: &str, apps: &str) -> Result<GpuReading, GpuParseError> {
    let lines = |text: &str| text.lines().filter(|line| !line.trim().is_empty()).map(str::to_owned).collect::<Vec<_>>();
    let bad = |line: &str| GpuParseError::Line { line: line.to_owned() };
    let gpus = lines(totals);
    if gpus.is_empty() {
        return Err(GpuParseError::NoGpu);
    }
    let (mut used, mut total) = (0_u64, 0_u64);
    for line in &gpus {
        let (u, t) = line.split_once(',').ok_or_else(|| bad(line))?;
        used = used.saturating_add(mib(u).ok_or_else(|| bad(line))?);
        total = total.saturating_add(mib(t).ok_or_else(|| bad(line))?);
    }
    let mut found = Vec::new();
    for line in &lines(apps) {
        let (pid, rest) = line.split_once(',').ok_or_else(|| bad(line))?;
        let (_name, memory) = rest.rsplit_once(',').ok_or_else(|| bad(line))?;
        let pid = pid.trim().parse().map_err(|_| bad(line))?;
        // nvidia-smi writes [N/A] here when it cannot read the process's memory.
        if let Some(used) = mib(memory) {
            found.push(GpuApp { pid, used });
        }
    }
    Ok(GpuReading { used, total, apps: found })
}
```

```rust
pub(crate) fn measure(inputs: &Inputs<'_>) -> Measures {
    let tree_of = |sheep: &str| -> BTreeSet<u32> {
        inputs
            .flock
            .iter()
            .filter(|row| row.name == sheep)
            .flat_map(|row| row.pid.into_iter().chain(row.lambs.iter().flatten().map(|lamb| lamb.pid)))
            .collect()
    };
    let runners = |blob: &str| -> BTreeSet<u32> {
        inputs.cmdlines.iter().filter(|(_, args)| loads(args, blob)).map(|(pid, _)| *pid).collect()
    };
    let vram_of = |pids: &BTreeSet<u32>| -> Option<u64> {
        let apps: Vec<_> = inputs.gpu?.apps.iter().filter(|app| pids.contains(&app.pid)).collect();
        (!apps.is_empty()).then(|| apps.iter().fold(0_u64, |sum, app| sum.saturating_add(app.used)))
    };
    let models = inputs
        .tracked
        .iter()
        .map(|tracked| {
            let measured = match &tracked.on {
                Where::Sheep(sheep) => Measured {
                    vram: vram_of(&tree_of(sheep)),
                    ram: inputs.flock.iter().find(|row| row.name == *sheep).and_then(|row| row.memory_bytes),
                },
                Where::Ollama { blob } => Measured {
                    vram: blob.as_deref().map(&runners).as_ref().and_then(&vram_of),
                    ram: None,
                },
            };
            (tracked.model.clone(), measured)
        })
        .collect();
    let all_loaded = inputs.tracked.iter().any(|tracked| tracked.declared.vram == Vram::All);
    let unaccounted_vram = inputs.gpu.filter(|_| !all_loaded).map(|gpu| {
        // Owned: what a tracked model's sheep runs, and ollama's runners. Nothing else (Spec readings 2).
        let mut owned: BTreeSet<u32> = inputs
            .tracked
            .iter()
            .filter_map(|tracked| match &tracked.on {
                Where::Sheep(sheep) => Some(tree_of(sheep)),
                Where::Ollama { .. } => None,
            })
            .flatten()
            .collect();

            owned.extend(runners(blob));

            .filter(|app| owned.contains(&app.pid))
```

```rust
//! Drift: a loaded model measured well above its declared footprint. Reported, never refused.

// The spec's figure: drift is a measurement more than 10% above the declared figure.
const DRIFT_OVER_PERCENT: u128 = 10;

pub(crate) fn drifts(declared: Footprint, measured: Measured) -> bool {
    let over = |declared: u64, measured: Option<u64>| {
        measured.is_some_and(|measured| {
            u128::from(measured) * 100 > u128::from(declared) * (100 + DRIFT_OVER_PERCENT)
        })
    };
    let vram = match declared.vram {
        Vram::All => false,
        Vram::None => over(0, measured.vram),
        Vram::Bytes(bytes) => over(bytes, measured.vram),
    };
    vram || over(declared.ram, measured.ram)
}

impl Drifting {
    pub fn update(&mut self, now: &BTreeMap<ModelName, (Footprint, Measured)>) -> Vec<String> {
        let mut lines = Vec::new();
        for (model, (declared, measured)) in now {
            if drifts(*declared, *measured) {
                if self.0.insert(model.clone()) {
                    lines.push(format!(
                        "paddock: {model} is drifting: it measures {} against {} declared",
                        measured_text(*measured),
                        declared_text(*declared)
                    ));
                }
            } else if self.0.remove(model) {
                lines.push(format!("paddock: {model} is back within its declared footprint"));
            }
        }
        self.0.retain(|model| now.contains_key(model));
        lines
    }

    pub fn contains(&self, model: &ModelName) -> bool {
        self.0.contains(model)
    }
}

/// `7000 MiB VRAM and 1504 MiB RAM`, with `unmeasured` for a figure not measured
fn measured_text(measured: Measured) -> String {
    let mib = |bytes: Option<u64>| bytes.map_or_else(|| "unmeasured".to_owned(), |bytes| format!("{} MiB", bytes >> 20));
    format!("{} VRAM and {} RAM", mib(measured.vram), mib(measured.ram))
}

/// `6144 MiB VRAM and 2048 MiB RAM`, with `all` and `no` for those VRAM declarations
fn declared_text(declared: Footprint) -> String {
    let vram = match declared.vram {
        Vram::All => "all".to_owned(),
        Vram::None => "no".to_owned(),
        Vram::Bytes(bytes) => format!("{} MiB", bytes >> 20),
    };
    format!("{vram} VRAM and {} MiB RAM", declared.ram >> 20)
}
```

Rules, from the spec's "Unaccounted GPU memory" and "Drift", and Spec readings 13:

1. With `Start.survey` set, the engine reads the host every `every` (30 s in the dog), never two surveys at once. A reading is: `Describe` of the flock, `/api/ps` of every configured ollama (one that does not answer is skipped without a log line; discovery logs it at start and the next survey asks again), each listed model's blob, `nvidia-smi`'s two queries, and the arguments of each GPU process. A `nvidia-smi` that prints something unreadable is logged and counts as absent.
2. A model's blob comes from the cache when its manifest digest is the one cached, and from `POST /api/show {"model": <ollama name>}` otherwise. The cache keeps only what the last reading listed.
3. Each model holding memory (Loading, Loaded, Evicting or Unloading) is measured against the footprint it counts at now; the snapshot shows its `measured` and `drift`, and `unaccounted_vram` comes from the last reading. Drift's start and end are logged, one line each.

```rust
// nvidia-smi answers in well under a second; one that hangs is a wedged driver.
const SMI_TIMEOUT: Duration = Duration::from_secs(5);

impl HostProbe for NvidiaSmi {
    fn gpu(&self) -> LocalBoxFuture<'_, Option<GpuText>> {
        async {
            let totals = smi(&["--query-gpu=memory.used,memory.total", "--format=csv,noheader"]).await?;
            let apps = smi(&["--query-compute-apps=pid,process_name,used_memory", "--format=csv,noheader"]).await?;
            Some(GpuText { totals, apps })
        }
        .boxed_local()
    }

    fn cmdline(&self, pid: u32) -> LocalBoxFuture<'_, Option<Vec<String>>> {
        // procfs answers from the kernel's memory, so this read does not block the thread.
        let args = std::fs::read(format!("/proc/{pid}/cmdline")).ok().map(|bytes| {
            bytes
                .split(|byte| *byte == 0)
                .filter(|arg| !arg.is_empty())
                .map(|arg| String::from_utf8_lossy(arg).into_owned())
                .collect()
        });
        core::future::ready(args).boxed_local()
    }
}

/// What `nvidia-smi` prints with `args`, or `None` when it is missing, fails or hangs
async fn smi(args: &[&str]) -> Option<String> {
    let run = tokio::process::Command::new("nvidia-smi").args(args).kill_on_drop(true).output();
    let output = tokio::time::timeout(SMI_TIMEOUT, run).await.ok()?.ok()?;
    output.status.success().then(|| String::from_utf8_lossy(&output.stdout).into_owned())
}
```

```rust
    fn sheep_touched_since(&self, sheep: &str, asked: Instant) -> bool {
        let configured = self
            .config
            .models
            .values()
            .filter(|model| model.backend.sheep() == Some(sheep))
            .map(|model| &model.name);
        configured
            .chain(self.on_sheep.get(sheep))
            .any(|model| self.touched_since(model, asked))
    }

    fn touched_since(&self, model: &ModelName, asked: Instant) -> bool {
        self.touched.get(model).is_some_and(|at| *at >= asked)
    }

    /// Counts the Online sheep the flock shows that nothing tracks, and forgets the sheep strays
    /// it shows not running
    pub(super) fn sheep_strays(&mut self, flock: Option<&[ProcessInfo]>, asked: Instant, busy: &HashSet<String>) {
        let Some(flock) = flock else {
            return;
        };
        let running = |sheep: &str| {
            flock
                .iter()
                .any(|row| row.name == sheep && matches!(row.status, ProcStatus::Starting | ProcStatus::Online))
        };
        for row in flock.iter().filter(|row| row.status == ProcStatus::Online) {
            if !busy.contains(&row.name) && self.untracked(&row.name) && !self.sheep_touched_since(&row.name, asked) {
                self.stray_sheep(&row.name);
            }
        }
        let gone: Vec<ModelName> = self
            .book
            .snapshot(self.clock.moment())
            .models
            .into_iter()
            .filter(|view| view.stray && view.state != State::Unloaded)
            .filter_map(|view| {
                let sheep = self.loaded_with.get(&view.name)?.backend.sheep()?.to_owned();
                let stale = running(&sheep) || self.sheep_touched_since(&sheep, asked);
                (!stale).then_some(view.name)
            })
            .collect();
        for model in gone {
            self.feed(Event::BackendExited { model });
        }
    }
```

```rust
/// Renews a lease, or records a note on it when the body carries one
async fn renew_or_note(shared: &Shared, client: &Client, lease: LeaseId, request: Request<Incoming>) -> Response<Body> {
    let body = match read_body(request.into_body(), shared.timeouts.body_read).await {
        Ok(body) => body,

    };

    };
    if note.len() > MAX_NOTE {

    }
```
