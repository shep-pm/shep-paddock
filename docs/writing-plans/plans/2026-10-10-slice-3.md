# Slice 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bare-footprint leases admitted against the host's totals like a load, `revoke` by an admin client, a bare job's GPU memory measured through the pid `shep paddock run` sends, and a containerised model measured through its podman container, on top of slices 1 and 2.

**Architecture:** The pure `Book` learns that a lease holds a model or a bare footprint (`Leased`), and that what holds or claims room is a model or a bare lease (`Taker`). So a bare lease goes through the same fit, eviction and reason code as a load: it claims the room an eviction frees for it, is never evicted, and is named in the reason of whatever it blocks. A revoke ends a lease; a bare one whose holder is attached keeps its memory counted until the holder detaches, which the engine learns by keeping that holder's stream open after the revoked line. Measurement stays out of the book (ADR 0002): the pure survey learns container figures (the pids in a cgroup) and bare jobs (GPU processes whose parent chain reaches a lease's pid), the engine's survey reads podman, `/proc` and `/sys/fs/cgroup` through `HostProbe`, and counts a container running without its model as a stray. HTTP threads the peer address so a pid is honoured only over loopback, and gains the footprint take body, the revoke route and the new status fields. The CLI gains `run --vram/--ram/--grace`, `revoke`, and the status columns.

**Tech Stack:** As slice 2: Rust 2024, MSRV 1.88, tokio (current-thread), hyper 1 + hyper-util + http-body-util, reqwest 0.13, shep-client 0.12, serde/serde_json/toml, schemars, jiff, subtle, proptest; tempfile for tests. No new dependency: `podman` runs as a subprocess, as `nvidia-smi` already does, and `/proc` and `/sys/fs/cgroup` are read as files.

**Spec:** `docs/brainstorming/specs/2026-10-10-slice-3-design.md`, binding. The slice 1 and slice 2 specs (`docs/brainstorming/specs/2026-10-04-slice-1-design.md`, `docs/brainstorming/specs/2026-10-06-slice-2-design.md`) hold wherever slice 3's is silent. Vocabulary: `CONTEXT.md`. Decisions: `docs/adr/0001` to `0003`. Read all of them before Task 1. The code this plan names is `main` at PR #18 (the per-model `sequences` limit), which the spec branch sits on.

## Spec readings this plan settles

Where the spec could be read two ways, this plan takes one reading. Implementers follow these and do not reopen them.

**Settled by the maintainer before the plan was written.** Recorded here so a reviewer finds them in one place.

- A. #17's per-model `sequences` shipped in PR #18. A lease that is not reclaimable takes a turn; a bare lease names no model, so it takes none.
- B. Revoke is `POST /paddock/leases/{id}/revoke` with an optional `{"reason": "…"}` of at most 1024 bytes, for clients marked `admin = true` only: `403` otherwise, `404` for a lease that has ended or never existed. `shep paddock revoke <id> [--reason …]` sends it. The stream's line is `{"ended":{"reason":"revoked","by":"<client>","note":"<reason>"}}`. A heartbeat holder's next renewal answers `404`. The dog's log records each revoke.
- C. A revoked model lease's `run` command runs on, and `run` says on stderr who revoked it and why. A revoked bare lease's `run` sends `SIGTERM` to its child, `SIGKILL` after `--grace` (default 30 s), and exits with the child's status; the book keeps the bare footprint counted until the holder detaches. A heartbeat bare lease's footprint is freed at the revoke.
- D. The take body's `pid` is honoured only when the request's peer address is loopback.
- E. A bare lease's take body has `footprint: {vram, ram}`, exclusive with `model`, sizes in shep's grammar or `all` for `vram`, at least one of the two present. One that can never fit the host is a `400`. `reclaimable` and `release_if_idle` on it are a `400`. It is always held, admitted on declared host totals like a load, may evict reclaimable models, and is named in reasons as `lease <id> of <client> (<vram> VRAM, <ram> RAM)`.
- F. A sheep model may name `container = "<podman container name>"`, refused on an ollama model. Each survey asks podman, as the dog's own user, for the container's main pid, reads that pid's cgroup (cgroup v2, under `/sys/fs/cgroup`) and the processes in it, and adds their resident memory and their `nvidia-smi` GPU memory to the sheep tree's as the model's measured figures. GPU memory in a container is not unaccounted. A podman that cannot be asked is logged once, and the model is measured by its sheep alone. A named container running while its model is not loaded is a stray of that model at its footprint, and unloading it stops the sheep and then runs `podman stop <name>`.
- G. A bare job's measured VRAM is the `nvidia-smi` memory of its pid and every process descended from it, with `drift` past 10% over its declared VRAM, reported only. A bare lease with no pid has its declared VRAM taken off unaccounted, floored at 0.
- H. `state.json` version 3 holds bare leases with their footprint and pid; versions 1 and 2 still load.
- I. No new dependency.

**Readings this plan takes.**

1. **The pid is `run`'s own.** As the spec says, `run` sends its own pid: it takes the lease before it spawns the child (`src/cli/run.rs`, `open` at line 323, `spawn` at 342), so no child pid exists when the take body is sent. `run` sends `std::process::id()`. Its child and everything the child starts descend from it, and `run` itself holds no GPU memory, so the measured figure is the same. Only a bare lease's take body carries it; a model lease's is unchanged.
2. **Descendants come from `/proc`.** A sheep's processes come from shep's flock (`ProcessInfo::lambs`, `src/survey/mod.rs`'s `tree`), which no bare job has, and slice 2 has no `/proc` descent code to reuse. The survey walks up from each `nvidia-smi` process instead, reading the parent from `/proc/<pid>/stat`, until it reaches a bare lease's pid, pid 1, an unreadable process or `PARENT_STEPS` steps. Only GPU processes need attributing, so this reads a handful of files, not the process table.
3. **A reason names a bare lease by the id a client sees:** `lease L12 of bench-01 (12G VRAM, 4G RAM)`, so the id in the reason is the one `shep paddock revoke` takes. Sizes are in shep's grammar; VRAM declared none reads `no VRAM`, declared `all` reads `all VRAM`, and RAM left out reads `0 RAM`. `LeaseId`'s `Display` becomes `L12`, and `render_id` uses it.
4. **The held sentence for a bare lease** substitutes its name for the model's: `lease L12 of bench-01 (12G VRAM, 4G RAM) is held by bench-01 since <time>`. It never says idle: the dog sees none of a bare job's use, so its `Reason::Held` carries no `idle_since`.
5. **A bare lease that commits an eviction claims the freed room**, as a Reserved model does, until the models leave and it is granted. It is told `evicting`, naming a model leaving for it: `qwen3.8:27b is evicting for lease L3 of bench-01 (8G VRAM, 2G RAM)`. A waiter that the claim keeps out is told `behind`: `room is claimed for lease L3 of bench-01 (8G VRAM, 2G RAM)`. A stray found, or a reload, drops every claim, bare ones included, so each claims again under the new figures.
6. **When no eviction of models can make room,** a bare lease or a bare claim is what holds it. The reason names the granted bare lease that ends last (no expected end counts as last, as `held_reason` picks among held models), else a bare lease's claim.
7. **The status lists a revoked bare lease while its job may still run**. A revoked bare lease whose holder was attached on a connection is listed, and counted, until the holder detaches. Any other revoked bare lease is freed at the revoke and listed until its hold would have ended: the renewal plus its `ttl`, or the detach plus `reconnect`. Each such row carries `"revoked": {"by": …, "note": …}`; every other row has `"revoked": null`. A revoked model lease is not listed.
8. **The revoked line and the stream.** For a bare lease whose holder is attached, the stream stays open after the revoked line, with its heartbeats, until the holder closes it, so the dog notices when `run` exits. Every other stream ends after its revoked line, as after any end.
9. **Revokes are not saved.** A revoked bare lease is not in `state.json`. A dog restart closes `run`'s connection, which is the condition that frees its memory anyway.
10. **A footprint names `vram`, `ram` or both.** `{}` is a `400 bad_lease_request`. A size of `0` counts as given. A footprint that can never fit the host is a `400` with `"error": "never_fits"`.
11. **`reclaimable` or `release_if_idle` present on a bare lease is a `400`**, even `"reclaimable": false`: the spec refuses the fields, not their values. `run --vram/--ram` refuses `--reclaimable` and `--release-if-idle` as a usage error, since the dog would refuse the take.
12. **A `pid` on a model lease is ignored.** A bare lease's `pid` from a peer that is not loopback is dropped before the engine sees it. Loopback is `127.0.0.0/8`, `::1`, and an IPv4-mapped `::ffff:127.0.0.0/104` address (`IpAddr::to_canonical`). A `run` on the GPU host whose `$PADDOCK_URL` names the host's LAN address is not loopback, so its pid is dropped and its declared VRAM comes off unaccounted instead.
13. **A bare lease's measured figures are VRAM only.** `measured.ram_bytes` is always null for it, and its drift reads VRAM alone. A bare lease declaring no VRAM drifts on any measured VRAM, as a model does (slice 2 reading 12). Its VRAM is unmeasured (null) while no GPU process descends from its pid.
14. **Per lease in the status:** `footprint` is `{"vram_bytes": …, "ram_bytes": …}` for a bare lease, where `all` reads as the host's VRAM and none as 0, as `vram_declared_bytes` counts them, and null for a model lease. `measured` is null for a model lease and an object (`{"vram_bytes": n|null, "ram_bytes": null}`) for a bare one. `drift` is always a boolean.
15. **Unaccounted with bare leases:** every bare lease the status lists is measured, and each one with no pid has its declared VRAM bytes taken off unaccounted. A bare lease declaring `vram = "all"` leaves unaccounted absent, as a model declaring `all` does.
16. **Every unload of a model that names a container runs `podman stop --ignore <name>` after its sheep stops,** stray or not, so the room the book frees is free. `--ignore` makes a container already gone (the Strata script's `--rm`) a success. A `podman stop` that fails or times out is logged, and the unload counts as done: the sheep is stopped, and a container still running turns up as a stray at the next survey if podman can be asked.
17. **Asking podman:** `podman container exists <name>` exiting 1 is "not running" (a stopped Strata container is removed by `--rm`, so `podman inspect` would only error), then `podman inspect --type container --format {{.State.Pid}} <name>` gives the main pid, where `0` is not running. Any other exit, a missing `podman`, an unreadable pid or a timeout is "podman cannot be asked". One container unreadable makes the whole survey's container reading unknown.
18. **A container's processes** are those in the `cgroup.procs` of the main pid's cgroup v2 path (its `0::` line) and of every cgroup below it, up to `CGROUP_DEPTH`. Their resident memory is each one's `VmRSS` from `/proc/<pid>/status`, summed. The container's RAM is added to the sheep's; with the flock unread it is the container's alone.
19. **Container names follow podman's grammar** (`[A-Za-z0-9][A-Za-z0-9_.-]*`), so one can never be read as a flag. Models on one sheep must name the same container or none (`SharedSheepMismatch` with `container`), and one container named on two sheep is refused (`SharedContainer`), since unloading its stray stops one sheep.
20. **A container stray is counted as its sheep's stray would be:** `discover::unrecorded` on its sheep, so the one model on that sheep, or the sheep's stand-in. A sheep stray whose model's container still runs is not forgotten when the sheep is gone. While podman cannot be asked, no container stray is found or forgotten.
21. **Logging a revoke:** `paddock: mac-sessions revoked lease L12 of bench-01 on iq2_xs: "forgotten since Tuesday"`, with `(12G VRAM, 4G RAM)` in place of `on <model>` for a bare lease and `no reason given` without a note.
22. **`shep paddock revoke`** exits 0 on `204`, 1 with a message on `403` ("this client is not an admin"), `404` ("lease … is gone") or anything else, and with the usage code when the id is missing.

## Review Focus

The five failure modes most likely to bite a person running this dog that the spec implies but does not spell out. Each line's test is written in the named task.

1. **The holder's connection broke before the revoke landed.** `run` lost its stream (a dog restart, a network blip) and is reattaching, or is dead, when the admin revokes. A reasonable person expects the memory freed at once, not counted until a detach that already happened. Test `a_bare_lease_whose_holder_had_detached_frees_its_memory_at_the_revoke`, Task 3.
2. **A container stray whose sheep is already stopped.** The container outlived its sheep, so unloading the stray stops a sheep that is not running. A reasonable person expects the unload to finish and the container to be stopped, not a stop retried forever. Test `unloading_a_container_stray_stops_the_sheep_then_the_container`, Task 10.
3. **podman missing, hung, or answering garbage.** A reasonable person expects the dog to keep serving, each model in a container measured by its sheep alone, and one log line per fault rather than one per survey. Tests `a_podman_that_cannot_be_asked_is_logged_once` in Task 9, and `an_unreadable_main_pid_is_podman_failing` (pure) in Task 9.
4. **A GPU process whose parent chain loops or never ends.** Pid reuse or a `/proc` read racing an exit can make `/proc` disagree with itself. A reasonable person expects the survey to finish and attribute nothing it cannot prove. Tests `a_parent_chain_that_loops_reaches_no_lease` in Task 9 (pure) and `a_survey_walking_a_looping_parent_chain_finishes` in Task 9 (engine).
5. **A bare lease asking for all the VRAM beside a model that holds only RAM.** A reasonable person expects it granted beside laya in RAM, and every VRAM model then refused naming it, with nothing evicted for nothing. Test `a_bare_lease_for_all_the_vram_fits_beside_a_model_that_holds_only_ram`, Task 2.

Rules, from the spec's "Bare-footprint leases" and readings 3 to 6:

1. A lease holds a model or a bare footprint. A bare lease takes no turn, is never reclaimable, and is never in use through the dog.
2. A bare lease is admitted against the host's totals as a load is: it fits beside the memory held now and the memory held or claimed once the models leaving are gone, with no exclusion (it names no model). A footprint that can never fit the host fails.
3. Without room, it evicts reclaimable models under slice 1's rules at its own priority (batch by default, so only models past `grace`), and claims the room until they leave. A claim counts against later loads and later bare leases as a Reserved model's does.
4. Once granted it holds its memory until it ends: it is in no eviction set and never unloads for idleness.
5. A reason names a bare lease as `Taker::Bare`, shown as `lease L12 of bench-01 (12G VRAM, 4G RAM)`. When evicting every model would not make room, the reason names the bare lease in the way that ends last, else a bare lease's claim.
6. The status's declared totals count every granted bare lease and every bare claim.

```rust
                .any(|(guard, name)| *guard == Guard::Held && set.contains(name))
        };

            .iter()
            .find(|set| !holds_held(set))
            .or_else(|| sets.first())
        else {
            // Evicting every model would not make room, so bare leases hold it.
            return self
                .bare_reason(now, skip)
                .unwrap_or_else(|| Reason::Behind { model: taker.clone() });
        };
        let guarded = |wanted: Guard| -> Vec<ModelName> {
            order
                .iter()
                .filter(|(guard, name)| *guard == wanted && set.contains(name))
                .map(|(_, name)| name.clone())
                .collect()
        };
        if let Some(held) = self.held_reason(now, &guarded(Guard::Held)) {
            return held;
        }
        if let Some(claimed) = guarded(Guard::Claim).into_iter().next() {
            return Reason::Behind {
                model: Taker::Model(claimed),
            };
        }
        self.grace_reason(now, &guarded(Guard::Grace))
            .unwrap_or_else(|| Reason::Behind { model: taker.clone() })
    }
```

```rust
                }

            Taker::Bare { lease, .. } => {
```

```rust
//! Bare leases: memory a job of the holder's own uses, admitted as a load is and never evicted.

use std::collections::BTreeSet;

use super::{
    Action, Book, LeaseAsk, LeaseId, Moment, Priority, Reason, Slot, State, Taker,
    admit::{Guard, Span},
    lease::Lease,

use crate::footprint::Footprint;

impl Book {
    /// What bare leases hold in `span`, leaving out the waiter at `skip`
    ///
    /// A granted bare lease holds its memory now and later. A waiting one whose
    /// eviction is committed claims it later.
    pub(super) fn bare_figures(&self, span: Span, skip: Option<(Priority, u64)>) -> Vec<Footprint> {
        let granted = self.leases.values().filter_map(|lease| lease.ask.bare());
        let claimed = self
            .waiters
            .iter()
            .filter(|(key, _)| span == Span::Later && Some(**key) != skip)
            .filter_map(|(_, waiter)| waiter.lease.as_ref())
            .filter(|ask| self.claims.contains(&ask.lease))
            .filter_map(LeaseAsk::bare);
        granted.chain(claimed).collect()
    }

    /// Grants the bare lease waiting at `key` once its memory fits, or makes room for it
    ///
    /// It must fit beside what is held now and what is held or claimed later,
    /// as a load must. Without room it evicts as a load would, at its own
    /// priority, and claims the room until the models leave. Returns why it
    /// still waits, or `None` once it is granted.
    pub(super) fn serve_bare(
        &mut self,
        now: Moment,
        key: (Priority, u64),
        out: &mut Vec<Action>,
    ) -> Option<Reason> {
        let ask = self.waiters.get(&key)?.lease.as_ref()?;
        let wanted = ask.bare()?;
        let taker = Taker::of(ask);
        let lease = ask.lease;
        let fits = |span| self.fits(None, wanted, &[], span, Some(key));
        if fits(Span::Now) && fits(Span::Later) {
            self.claims.remove(&lease);
            self.unclaim(&taker);
            let waiter = self.waiters.remove(&key)?;
            self.admit(now, waiter, out);
            return None;
        }
        if self.claims.contains(&lease)
            && let Some(reason) = self.leaving_for(&taker)
        {
            return Some(reason);
        }
        let order = self.in_the_way(now, None, key.0);
        let free: Vec<_> = order
            .iter()
            .filter(|(guard, _)| *guard == Guard::Free)
            .map(|(_, name)| name.clone())
            .collect();
        if let Some(set) = self.eviction_set(None, wanted, free, Some(key)) {
            self.evict(set, &taker, out);
            let reason = self.leaving_for(&taker);
            return Some(reason.unwrap_or(Reason::Behind { model: taker }));
        }
        Some(self.blocked(now, &taker, &[(None, wanted)], &order, Some(key)))
    }

    /// Why a bare lease whose eviction is committed still waits: a model leaving for it, else
    /// any model leaving
    fn leaving_for(&self, taker: &Taker) -> Option<Reason> {
        let leaving = |slot: &Slot| matches!(slot.state, State::Evicting | State::Unloading);
        let (model, slot) = self
            .slots
            .iter()
            .find(|(_, slot)| leaving(slot) && slot.for_model.as_ref() == Some(taker))
            .or_else(|| self.slots.iter().find(|(_, slot)| leaving(slot)))?;
        Some(match &slot.for_model {
            Some(for_model) => Reason::Evicting {
                model: model.clone(),
                for_model: for_model.clone(),
            },
            None => Reason::Draining {
                model: model.clone(),
            },
        })
    }

    /// The reason naming the bare lease in the way that ends last, else a bare lease's claim
    ///
    /// A lease that gave no expected end, or whose end has passed, counts as
    /// ending last. The dog sees none of a bare job's use, so it is never idle.
    pub(super) fn bare_reason(&self, now: Moment, skip: Option<(Priority, u64)>) -> Option<Reason> {
        let until = |lease: &Lease| lease.until().filter(|at| *at > now);
        let held = self
            .leases
            .values()
            .filter(|lease| lease.ask.bare().is_some())
            .max_by_key(|lease| (until(lease).is_none(), until(lease), lease.ask.lease));
        if let Some(lease) = held {
            return Some(Reason::Held {
                model: Taker::of(&lease.ask),
                client: lease.ask.client.clone(),
                lease: lease.ask.lease,
                since: lease.since,
                until: until(lease),
                idle_since: None,
            });
        }
        self.waiters
            .iter()
            .filter(|(key, _)| Some(**key) != skip)
            .filter_map(|(_, waiter)| waiter.lease.as_ref())
            .find(|ask| self.claims.contains(&ask.lease))
            .map(|ask| Reason::Behind {
                model: Taker::of(ask),
            })
    }

    /// Drops the claim of every bare lease no longer waiting, and stops evictions naming it
    ///
    /// Evictions committed for a dropped claim stand. Returns whether any claim was dropped.
    pub(super) fn drop_bare_claims(&mut self) -> bool {
        let waiting: BTreeSet<LeaseId> = self
            .waiters
            .values()
            .filter_map(|waiter| waiter.lease.as_ref())
            .map(|ask| ask.lease)
            .collect();
        let before = self.claims.len();
        self.claims.retain(|lease| waiting.contains(lease));
        let claims = &self.claims;
        for slot in self.slots.values_mut() {
            if matches!(&slot.for_model, Some(Taker::Bare { lease, .. }) if !claims.contains(lease)) {
                slot.for_model = None;
            }
        }
        self.claims.len() != before
    }
}
```

Rules, from the spec's "Revoke" and readings 7 to 9:

1. A revoke ends a granted lease with `Ended::Revoked`, and saves. A lease not granted, or already ended, is left alone.
2. A revoked model lease just ends: its model stays loaded and becomes reclaimable unless another lease holds it, as after an idle end.
3. A revoked bare lease whose holder is attached on a connection stays counted, and is listed as revoked, until `HolderDetached` for it.
4. Any other revoked bare lease frees its memory at the revoke and is listed as revoked until its hold would have ended: its renewal plus `ttl`, or its detach plus `reconnect`. That end is a deadline, so a `Tick` drops it.
5. A revoked lease is gone for `lease()`, so a renewal, note, attach, release or second revoke finds nothing.

```rust
//! Revoking a lease, and the revoked bare leases whose job may still run.

use super::{
    Action, Book, Ended, Hold, LeaseId, LeaseView, Moment,
    lease::{Lease, Revocation},
};

/// A revoked bare lease, listed while its job may still run
#[derive(Debug)]
pub(super) struct Revoked {
    pub(super) lease: Lease,
    pub(super) by: Revocation,
    /// Its holder was attached when it was revoked, so its memory stays counted until it detaches.
    pub(super) counted: bool,
}

impl Book {
    /// Ends lease `id`, revoked as `by` says
    ///
    /// A bare lease whose holder is attached on a connection keeps its memory
    /// counted until the holder detaches, since its job may still run. Any other
    /// bare lease frees its memory now, and is listed until its hold would have
    /// ended. A model lease just ends, and its model stays loaded.
    pub(super) fn revoke(&mut self, id: LeaseId, by: Revocation, out: &mut Vec<Action>) {
        let Some(lease) = self.leases.remove(&id) else {
            return;
        };
        out.push(Action::LeaseEnded {
            lease: id,
            why: Ended::Revoked(by.clone()),
        });
        out.push(Action::Persist);
        if lease.ask.bare().is_some() {
            let counted = lease.ask.hold == Hold::Connection && lease.attached();
            self.revoked.insert(id, Revoked { lease, by, counted });
        }
    }

    /// Forgets each revoked bare lease that holds no memory and whose hold would have ended by `now`
    pub(super) fn expire_revoked(&mut self, now: Moment) {
        let reconnect = self.config.reconnect;
        self.revoked.retain(|_, revoked| {
            revoked.counted || revoked.lease.ends_at(reconnect).is_some_and(|at| at > now)
        });
    }

    /// When each revoked bare lease that holds no memory stops being listed
    pub(super) fn revoked_ends(&self) -> impl Iterator<Item = Moment> + '_ {
        self.revoked
            .values()
            .filter(|revoked| !revoked.counted)
            .filter_map(|revoked| revoked.lease.ends_at(self.config.reconnect))
    }

    /// Each revoked bare lease the status still lists, marked revoked
    pub(super) fn revoked_views(&self) -> impl Iterator<Item = LeaseView> + '_ {
        self.revoked.values().map(|revoked| LeaseView {
            revoked: Some(revoked.by.clone()),
            ..revoked.lease.view(false)
        })
    }
}
```

```rust
//! `POST /paddock/leases/{id}/revoke`: an admin client ends any client's lease.

use hyper::{Request, Response, StatusCode, body::Incoming};
use serde::Deserialize;

use super::{BadTake, MAX_NOTE, answer, bad_take, refused};
use crate::{
    book::LeaseId,
    config::Client,
    engine::LeaseRefused,
    http::{Body, Shared, proxy::read_body, reply},
};

/// The body of a revoke, which may also be empty
#[derive(Debug, Deserialize)]
#[serde(deny_unknown_fields)]
struct Revoke {
    reason: Option<String>,
}

/// Revokes `lease`, `None` for an id that names no lease, as `client`
///
/// A client that is not an admin is refused before anything else is read.
pub(super) async fn revoke(
    shared: &Shared,
    client: &Client,
    lease: Option<LeaseId>,
    request: Request<Incoming>,
) -> Response<Body> {
    if !client.admin {
        return reply::error(StatusCode::FORBIDDEN, "forbidden");
    }
    let Some(lease) = lease else {
        return refused(LeaseRefused::NotFound);
    };
    let body = match read_body(request.into_body(), shared.timeouts.body_read).await {
        Ok(body) => body,
        Err(bad) => return bad.reply(),
    };
    let reason = if body.is_empty() {
        None
    } else {
        match serde_json::from_slice::<Revoke>(&body) {
            Ok(revoke) => revoke.reason,
            Err(err) => return bad_take(&BadTake::Body(err.to_string())),
        }
    };
    if reason.as_ref().is_some_and(|reason| reason.len() > MAX_NOTE) {
        return bad_take(&BadTake::ReasonTooLong);
    }
    answer(shared.engine.revoke(client.name.clone(), lease, reason).await)
}
```

1. A bare job's VRAM is the sum of the `nvidia-smi` processes whose parent chain, as the survey read it, reaches its lease's pid; unmeasured while none does or without a GPU reading. Its RAM is never measured.

```rust
/// Every pid in the cgroup at `dir` and the cgroups below it, as far as they can be read
pub(crate) fn cgroup_tree(dir: &Path) -> BTreeSet<u32> {
    let mut pids = BTreeSet::new();
    let mut dirs = vec![(dir.to_path_buf(), 0)];
    while let Some((dir, depth)) = dirs.pop() {
        if let Ok(text) = std::fs::read_to_string(dir.join("cgroup.procs")) {
            pids.extend(procs(&text));
        }
        if depth == CGROUP_DEPTH {
            continue;
        }
        for entry in std::fs::read_dir(&dir).into_iter().flatten().flatten() {
            if entry.file_type().is_ok_and(|kind| kind.is_dir()) {
                dirs.push((entry.path(), depth + 1));
            }
        }
    }
    pids
}

/// The pids in `pid`'s cgroup and below it, or `None` when its cgroup cannot be read
pub(crate) fn cgroup_pids(pid: u32) -> Option<BTreeSet<u32>> {

    let path = cgroup_path(&text)?;
    Some(cgroup_tree(&Path::new(CGROUP_ROOT).join(path.trim_start_matches('/'))))
}
```

```rust
/// What `program` exits with and prints with `args`, or `None` when it is missing or runs past
/// `limit`
///
/// One that runs past `limit` is killed, and this returns only once it is reaped.
pub(super) async fn exec(
    program: &OsStr,
    args: &[&str],
    limit: Duration,
) -> Option<(Option<i32>, String)> {
    let mut child = tokio::process::Command::new(program)
        .args(args)
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .kill_on_drop(true)
        .spawn()
        .ok()?;
    let mut stdout = child.stdout.take()?;
    let mut printed = Vec::new();
    let ran = tokio::time::timeout(limit, async {
        let (read, status) = tokio::join!(stdout.read_to_end(&mut printed), child.wait());
        read.ok().and(status.ok())
    })
    .await;
    let Ok(status) = ran else {
        let _ = child.start_kill();
        let _ = child.wait().await;
        return None;
    };
    Some((status?.code(), String::from_utf8_lossy(&printed).into_owned()))
}
```

```rust
/// Reads the parent of `pid`, and of each ancestor, into `parents`, until one is a bare lease's
/// pid, pid 1, unreadable, already read, or [`PARENT_STEPS`] up
async fn walk_up(
    host: &dyn HostProbe,
    pid: u32,
    roots: &BTreeSet<u32>,
    parents: &mut BTreeMap<u32, u32>,
) {
    let mut at = pid;
    for _ in 0..PARENT_STEPS {
        if roots.contains(&at) || at <= 1 || parents.contains_key(&at) {
            return;
        }
        let Some(parent) = host.parent(at).await else {
            return;
        };
        parents.insert(at, parent);
        at = parent;
    }
}
```

```rust
        let name = name.to_owned();

            let stopping = tokio::process::Command::new("podman")
                .arg("stop")
                .arg("--ignore")
                .arg(&name)
                .stdin(Stdio::null())
                .stdout(Stdio::null())
                .stderr(Stdio::null())
                .kill_on_drop(true)
                .status();

                Ok(Err(err)) => Err(format!("podman could not be run: {err}")),
                Err(_) => Err(format!("podman stop {name} did not end within {STOP_TIMEOUT:?}")),
            }
        }
        .boxed_local()
    }
}
```

```rust
/// What the holder's stream is doing while the command runs
enum Watch {
    Streaming(Stream),
    /// The stream broke; attach again until `until`.
    Reattaching {
        until: Instant,
    },
    /// The bare lease was revoked, so the command is being stopped: `TERM` once `termed`, then
    /// `KILL` at `kill_at`, after which it is `None`. The stream stays open, so the dog counts
    /// the memory until `run` exits.
    Stopping {
        /// Held, never read: dropping it would close the connection.
        _stream: Stream,
        termed: bool,
        kill_at: Option<Instant>,
    },
    /// The lease is gone, and there is nothing to attach to or release.
    Gone,
}

impl Watch {
    /// Takes one step, then returns; `Gone`, and `Stopping` once the command is killed, never do
    ///
    /// # Cancellation safety
    /// Safe: a step cut short by the command's exit or a signal leaves a state the next step
    /// carries on from, at worst sending a signal twice.
    async fn step(
        &mut self,
        client: &reqwest::Client,
        link: &Link,
        held: &Held<'_>,
        err: &mut impl Write,
    ) {
        match self {
            Self::Streaming(stream) => match stream.next(link.silence).await {
                Next::Event(Event::Ended {
                    reason,
                    idle_for,
                    by,
                    note,
                }) => {
                    let said = ended_message(
                        &reason,
                        idle_for.as_deref(),
                        by.as_deref(),
                        note.as_deref(),
                        held.bare,
                    );
                    say(err, said);
                    let stopping = reason == "revoked" && held.bare;
                    let Self::Streaming(stream) = core::mem::replace(self, Self::Gone) else {
                        return;
                    };
                    if stopping {
                        *self = Self::Stopping {
                            _stream: stream,
                            termed: false,
                            kill_at: Some(Instant::now() + held.grace),
                        };
                    }
                }
                Next::Event(_) => {}
                Next::Broken => {
                    say(
                        err,
                        "the connection to the dog broke; trying to attach again",
                    );
                    *self = Self::Reattaching {
                        until: Instant::now() + held.reconnect,
                    };
                }
            },
            Self::Stopping {
                termed, kill_at, ..
            } => {
                if !*termed {
                    if let Some(pid) = held.pid {
                        send_signal(pid, "TERM", err).await;
                    }
                    *termed = true;
                    return;
                }
                let Some(at) = *kill_at else {
                    return core::future::pending().await;
                };
                sleep_until(at).await;
                say(
                    err,
                    format_args!(
                        "the command did not stop within {}; killing it",
                        rough(held.grace)
                    ),
                );
                if let Some(pid) = held.pid {
                    send_signal(pid, "KILL", err).await;
                }
                *kill_at = None;
            }
            Self::Reattaching { until } => {
                sleep(link.retry).await;
                if Instant::now() >= *until {
                    say(
                        err,
                        "the reconnect time ran out; letting the command finish",
                    );
                    *self = Self::Gone;
                    return;
                }
                let path = format!("/paddock/leases/{}/attach", held.id);
                match open(client, link, &path, None).await {
                    Ok(stream) => *self = Self::Streaming(stream),
                    Err(Rejected::Status(
                        StatusCode::NOT_FOUND | StatusCode::FORBIDDEN | StatusCode::UNAUTHORIZED,
                        _,
                    )) => {
                        say(err, "the lease is gone; letting the command finish");
                        *self = Self::Gone;
                    }
                    Err(_) => {}
                }
            }
            Self::Gone => core::future::pending().await,
        }
    }

    /// Whether the lease has ended, so there is nothing to release
    fn ended(&self) -> bool {
        matches!(self, Self::Gone | Self::Stopping { .. })
    }
}
```

```rust
//! `shep paddock revoke`: end any client's lease, as an admin client.

use std::{io::Write, time::Duration};

use reqwest::{Method, StatusCode};
use serde_json::json;

use super::{Link, note::segment, say};
use crate::outbound::http_client;

// The dog answers a revoke from memory; ten seconds is a dog that is not answering.
const REQUEST_TIMEOUT: Duration = Duration::from_secs(10);

/// Revokes lease `id`, giving `reason` when there is one, and returns the exit code
///
/// A `403` says this client is not an admin, a `404` that the lease is gone. Either, or any
/// answer but `204`, exits 1.
pub(crate) async fn revoke(
    link: &Link,
    id: &str,
    reason: Option<&str>,
    err: &mut impl Write,
) -> u8 {
    let client = http_client();
    let path = format!("/paddock/leases/{}/revoke", segment(id));
    let mut request = link
        .request(&client, Method::POST, &path)
        .timeout(REQUEST_TIMEOUT);
    if let Some(reason) = reason {
        request = request
            .header(reqwest::header::CONTENT_TYPE, "application/json")
            .body(json!({ "reason": reason }).to_string());
    }
    let response = match request.send().await {
        Ok(response) => response,
        Err(failure) => {
            say(
                err,
                format_args!("cannot reach the dog at {}: {failure}", link.url),
            );
            return 1;
        }
    };
    match response.status() {
        StatusCode::NO_CONTENT => 0,
        StatusCode::FORBIDDEN => {
            say(err, "this client is not an admin, so it cannot revoke a lease");
            1
        }
        StatusCode::NOT_FOUND => {
            say(err, format_args!("lease {id} is gone"));
            1
        }
        code => {
            let body = response.text().await.unwrap_or_default();
            say(err, format_args!("the dog answered {code}: {body}"));
            1
        }
    }
}
```
